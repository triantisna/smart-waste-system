## 📁 Struktur Folder di Google Drive

Di dalam Google Drive tersebut, dataset dikelompokkan ke dalam kategori berikut:

```text
dataset/
├── Organic Waste/      # Kumpulan citra sampah organik (sisa makanan, daun, dll)
├── Plastic Waste/      # Kumpulan citra sampah plastik (botol, kemasan, dll)
└── Paper Waste/        # Kumpulan citra sampah kertas (kardus, kertas cetak, dll)
```
